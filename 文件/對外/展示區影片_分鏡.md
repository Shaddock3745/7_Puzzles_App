# 展示區循環影片：分鏡表

> 2026-11-04 開始。決賽展示區（三樓，07:00～17:00）筆電 B 整天**循環播**的影片。
> 跟〈製作過程影片〉是兩支：那支講開發過程、給評審；**這支給路人看**，任務是讓人停下來、走到桌上的 iPad 試玩。
> 規格與內容定案寫這裡；製作檔放 `報告_期中與決賽/製作檔/展示區影片/`（不進版控）。

## 定案（2026-11-04）

| 項目 | 定案 | 理由 |
|---|---|---|
| 長度 | **60 秒**（使用者定） | 排隊等試玩的人看得完一圈；同一句話一小時只重複 60 次 |
| 形式 | **動畫為主＋實機畫面＋AI 配音＋大字幕** | 使用者：「不要像另一邊一樣死氣沉沉」 |
| 循環 | **沒有片頭、沒有結尾卡**；最後一格＝第一格（七片拼成的正方形） | 路人多半從中間開始看，接縫看不出來才像一直在播 |
| 每一段單獨看得懂 | 不用「第一、第二」、不用「剛剛說的」 | 同上 |
| 字幕比配音重要 | 每句話都上大字；聽不到也看得懂 | 展示區吵，筆電喇叭蓋不過人聲 |
| 筆電 B 播什麼 | **展示區只播這一支**（使用者 11/4）；製作過程影片不在展示區播 | 路人不會看 3 分 50 秒的開發過程 |
| 音量 | 喇叭有旋鈕，現場調；不另外安排靜音時段 | 競賽區就在旁邊，報告時段顧攤的人把聲音轉小 |
| 重拍 | **可以重拍**（使用者 11/4） | 舊的 `raw_t20.mp4` 是手持拍平板（入鏡鍵盤、反光、手擋畫面）；`raw_scan.mp4` 拍的是有品牌標籤的眼藥水 |

### 不放的東西（跟海報同一套規矩）

- 開發的數字（測試數、看板、天數）、ELO 這類名詞
- 學校、課程、教授；年齡段（寫「玩家」，不寫孩子、小朋友）
- 「不用生成式 AI」那句——影片本身用 AI 配音，放在一起會被抓（那句話講的是 App，留在紙上就好）

## 分鏡（60 秒）

| 秒 | 段 | 畫面 | 配音＝字幕 | 素材 |
|---|---|---|---|---|
| 0–5 | 開場 | 正方形的七片炸開、轉著飛散，再一片一片「喀」地吸附，拼成一個造型；「巧級 Tangrade」彈出 | 「七片，能拼出幾種形狀？數不完。」 | 動畫 |
| 5–17 | 當場出題 | 七片隨機落下拼成一個形狀 → 外框描線亮起 → 片淡出只剩剪影 → 剪影飛進一面一直長的剪影牆 | 「這裡的每一題，都是電腦當場拼好、再描下外框做成的。題目永遠不會用完，而且保證拼得出來。」 | 動畫 |
| 17–32 | 跟著你變強 | 左：實機一題快轉、過關彈窗「下一題會難一點」正常速度；右：實力條往上爬；三個剪影由簡到難排開 | 「拼得越順，下一題就難一點；卡住了，就簡單一點。難度不是猜的，是從外框的形狀算出來的。」 | 重拍 R1＋動畫 |
| 32–50 | 拍照變題目 | 實機：拍一樣東西 → 等待（快轉，角落小字「實際要等一下」）→ 選題畫面翻頁 → 剪影疊照片 → 拼幾片 | 「看到喜歡的東西？拍下來。系統用七片拼出最像它的樣子，變成一道題。」 | 重拍 R2＋動畫外框 |
| 50–60 | 邀請、接回開頭 | 大字「旁邊的平板就能玩」＋箭頭 → 造型的七片散開、飛回正方形（＝第 0 秒那格） | 「來拼一題吧！」 | 動畫 |

第 0～1 秒與第 59～60 秒不放人聲，接縫才聽不出來。

## 怎麼做的（2026-11-04 第一版預覽）

製作檔在 `報告_期中與決賽/製作檔/展示區影片/`，成品是 `報告_期中與決賽/展示區影片.mp4`（都不進版控）。

| 檔案 | 做什麼 |
|---|---|
| `showcase.html` | 動畫本體：給一個時間點就畫出那一格。直接用瀏覽器開就會播（空白鍵暫停、←→ 跳 1 秒、`?t=12` 從第 12 秒開始）。**要調的東西都在最上面**：開場造型、哪一題、配音每句的起點與長度、錄影框位、掃描三步亮起的時間 |
| `shapes.js` | 出題器生的 60 個形狀（縮圖牆工具 `ExportThumbnailWall` 匯出、照難度分位挑），「當場出題」、剪影牆、三個難度用的 |
| `figures.js` | 題庫 38 題（`puzzle_library.txt`）解碼成每片的座標：開場的貓、結尾的正方形、掃描段的茶壺。用 scratchpad 的小程式匯出，題庫沒改就不用重匯 |
| `render.py` | 無頭 Edge 一格一格叫 `renderAt(t)`、拿畫布的 PNG（錄影框位是透明的）。`check` 抽 18 格拼總覽圖，`full` 輸出 1800 格（約 20 秒） |
| `edit_footage.py` | 從螢幕錄影剪出 `R1.mp4`（14 秒）與 `R2.mp4`（18 秒）：每段的來源起訖、快轉倍數、馬賽克框都寫在檔案最上面的表 |
| `voice.py` | 配音：每句拆幾小段分開念，每段自己的語速、音高、音量，段間留停頓（edge-tts 對雲哲只能調這三樣，抑揚頓挫靠段跟段不一樣），頭尾空白修掉。產出每句的 mp3 與 `voice.js`（動畫頁的字幕、實力條、三張卡都照它的時間）。⚠️ **「數不完」會被念成ㄕㄨˋ，所以送「鼠不完」去念**，字幕照舊 |
| `music.py` | ⭐ 配樂＋音效（11/4 使用者：舊配樂「有點乾，要大聲、活潑一點」→ 重做）：numpy 合成，128 BPM、C–G–Am–F、60 秒剛好 32 小節，鼓、八度跳的貝斯、切分和弦、木琴旋律；每個音與殘響都繞回開頭，循環接縫天生對得上。**配音那幾段自動壓低**（量過：壓低後配樂比人聲低約 7 dB，沒人聲時跟人聲一樣大）。音效照動畫頁的 `soundEvents()` 時間表放：吸附「叮」（七片一片比一片高）、飛的「咻」、彈出的「啵」、描外框 |
| `build.py` | 合成：錄影墊在動畫底下、配樂＋音效＋五句配音混好，**整支用同一個增益**拉到 −15 LUFS 再限幅（不用 loudnorm 單次模式：增益會飄，循環接縫會跳）。同資料夾有 `R1.mp4`／`R2.mp4` 就用，沒有就拿舊錄影當替身 |

重做的順序：`voice.py`（改了配音才要）→ `render.py full` → `music.py` → `build.py <TEMP>\tangrade_showcase\voice zh-TW-YunJheNeural`。動畫的時間改了，音效與壓低的時間跟著 `render.py` 寫出的 `config.json` 走，所以 `music.py` 要在它後面重跑。

工具：Python 要有 `edge-tts`、`aiohttp`、`Pillow`（11/4 裝在 scratchpad 的 venv）；ffmpeg 用 Krita 附的那支，**它不吃中文路徑也沒有 lavfi**，所以中間檔一律放 `%TEMP%\tangrade_showcase`。
