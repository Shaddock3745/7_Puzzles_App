## 一、要做什麼

把這個 Unity 專案打包成 iPad 上的 App，裝到你的 iPad 上跑一輪，然後回報結果（第五節、第六節）。

這是一個七巧板拼圖遊戲（作品名稱「巧級／Tangrade」），參加大專校院資訊應用服務創新競賽。決賽的展示機是一台 Android 平板，**iPad 是額外試的**——跑得起來最好，跑不起來也要知道卡在哪裡。

到目前為止，這個專案**只在 Android 與 Windows 上跑過**。iOS 的程式只做到「編譯得過」，**沒有在真的 iPhone／iPad 上跑過**，所以你是第一個。

## 二、要準備的東西

| 東西 | 說明 |
|---|---|
| Mac | 要能裝 Xcode |
| **Xcode** | 用 App Store 上最新的正式版。打包時 Unity 如果說版本太舊或太新，照它的訊息處理 |
| **Unity Hub ＋ Unity 6000.3.7f1** | ⚠️ **版本要一模一樣**，不要用別的 6000.x。Hub 裡找不到的話到 Unity 的下載封存頁找這個版本。安裝時**勾選 iOS Build Support** 模組 |
| **git 與 git-lfs** | ⚠️ **一定要先裝 git-lfs**（例如 `brew install git-lfs`，然後 `git lfs install`）。字型與圖片走 LFS，沒裝的話 clone 下來只是幾行文字，Unity 會出現一堆缺圖、缺字的錯誤 |

| Apple ID | 免費的就可以裝到自己的 iPad 上（App 7 天後要重裝）；有付費開發者帳號更好 |
| iPad | iPadOS 15 以上。iPadOS 16 以上要先打開**開發者模式**（設定 → 隱私權與安全性 → 開發者模式） |

## 三、取得專案

```bash
git lfs install
git clone https://github.com/Shaddock3745/7_Puzzles_App.git
```

用 Unity Hub「Add → 從磁碟加入」打開資料夾，**版本選 6000.3.7f1**。

⚠️ **第一次打開會很久**：Unity 要下載套件，其中兩個要注意——

- **NativeGallery**（選相簿照片用）是用 git 網址裝的，所以 Mac 上要有 git
- **com.unity.ai.inference**（照片 → 輪廓的辨識模型用）比較大

打開之後 Console 如果有紅字，先看是不是 LFS 沒拉到（第二節）。

## 四、切平台、調設定、打包

### 1. 切到 iOS

**File → Build Profiles → iOS → Switch Platform。**

💡 切完之後 `ProjectSettings/ProjectSettings.asset` 會被改到（推論套件會自動加編譯符號），**這是正常的**。

打包的場景只有一個：`Assets/Scenes/GameScene.unity`（已經設好、不用動）。

### 2. 要調的設定（都是你的事）

| 在哪裡 | 設什麼 | 為什麼 |
|---|---|---|
| Player Settings → iOS → Other Settings → **Camera Usage Description** | 一句話，例如「用相機拍下物品，把它的輪廓變成七巧板題目。」 | ⚠️ **現在是空的**。iOS 規定要有這句才能開相機，沒填的話「新拍一張」會打不開（或 App 直接被系統關掉） |
| Player Settings → iOS → Other Settings → **Bundle Identifier** | 你自己的，例如 `com.你的名字.tangrade` | 現在只設了 Windows 版的，iOS 沒設。簽章要用 |
| Player Settings → iOS → Other Settings → **Signing Team ID**（或打包後在 Xcode 裡設） | 你的 Apple ID 的 Team | 簽章 |
| Project Settings → **yasirkula → Native Gallery** → Photo Library Usage Description | 可以不改（有英文預設），想改成中文就改，例如「從相簿選一張照片，把物品的輪廓變成七巧板題目。」 | 相簿用的說明字串。iOS 14 以上選照片不用權限，這句多半不會出現，但 iOS 規定要有 |
| Player Settings → iOS → **Resolution and Presentation** | **建議不動** | 現在是自動旋轉、只允許**直式**（正拿與倒拿），遊戲版面是照直式做的 |

最低 iOS 版本已經設成 15.0，不用改。

### 3. 打包

**Build Profiles → Build**，選一個空資料夾 → Unity 產生一個 Xcode 專案 → 用 Xcode 打開 `Unity-iPhone.xcodeproj` →
在 **Signing & Capabilities** 勾 Automatically manage signing、選你的 Team → 接上 iPad、選它當目標 → Run。

用免費 Apple ID 的話，第一次裝完要在 iPad 上：設定 → 一般 → VPN 與裝置管理 → 信任你的開發者帳號，App 才打得開。

## 五、裝好之後測什麼

主畫面有三個模式：**挑戰模式**（照實力出題）、**具象題**（貓、船之類的固定題）、**掃描模式**（拍一個東西變成一題）。
玩法是把下方抽屜裡的七片拖進盤面上的框框裡填滿；點一片會出現旋轉、翻面鈕。

⭐ **Xcode 的 Console 會印出 App 的 log**（Run 的時候下方的輸出區），下面要你記的數字都在那裡，**請整段複製給負責人**。

| # | 做什麼 | 要看什麼 |
|---|---|---|
| 1 | 打開 App | 能不能開、會不會閃退。閃退的話把 Xcode Console 最後一段紅字複製下來 |
| 2 | 停在主畫面幾秒，按**挑戰模式** | 有沒有馬上進關。Console 找「**玩家等了**」那一行，記下秒數；還有「**第一次進關的暖機**」那一行 |
| 3 | 拼完一題（或按放棄），結果彈窗一出來就**馬上**按下一題 | 有沒有卡住。等的時候畫面會寫「出題中…」而且點在動，好了自動進關。再記一次「玩家等了」 |
| 4 | 拖片、旋轉、翻面、抽屜開關 | 手指操作正不正常、版面有沒有跑掉、按鈕會不會太小或被切到 |
| 5 | **掃描模式 → 新拍一張** | 第一次會跳相機權限 → 允許 → ⭐ **預覽畫面是不是正的**：iPad 直拿、倒拿各試一次（橫拿 App 不會跟著轉，那是正常的）。**歪了、顛倒、左右相反都請拍照給負責人看**，這是 iOS 最可能出錯的地方 |
| 6 | 拍一個放在乾淨桌面上的東西（杯子、剪刀、鞋子之類輪廓清楚的） | 畫面會寫「辨識中…」→「出題中…」→ 出現選題畫面（照片＋候選題目的剪影，可以翻頁）→ 選一個 → 進關。Console 記下「**逼近合計**」那一行的秒數 |
| 7 | 進關後按**照片**鈕 | 拍的照片半透明疊在框框上，**位置、方向要對得上**（照片是正的、跟框的形狀疊在一起） |
| 8 | **掃描模式 → 從檔案選擇** | 會跳出系統的照片選擇器（不會問權限）→ 選一張 → 跟第 6、7 條一樣 |
| 9 | 關掉 App 再打開，玩挑戰模式 | 實力有沒有接著上次（Console 開頭會有「實力從存檔讀到 …」） |

## 七、已知的事（看到不用緊張）

- **橫拿 iPad 畫面不會轉**：刻意只開直式
- **監控面板（分數怎麼算的那個視窗）只在電腦版 Unity 裡有**，App 裡看不到
- **掃描模式不會改變實力**，結果彈窗寫「再來一題」是正常的
- 第一次進掃描模式比較慢（辨識模型要載入）
- 辨識不一定準：背景雜、物體太細（例如筷子）時，出來的題目會不太像，那是演算法的限制，不是 iOS 的問題
